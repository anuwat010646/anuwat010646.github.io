ระบบดูแลต้นบอนไซอัจฉริยะ

ESP32 วัดความชื้นในดิน อุณหภูมิ และความชื้นในอากาศ แล้วรดน้ำกับพ่นหมอกให้อัตโนมัติ จุดที่ไม่เหมือนใครคือดูสถานะและสั่งรดน้ำจากในเกม Minecraft ได้ ต้นไม้ในโลกจำลองกับต้นไม้จริงเชื่อมกันผ่าน MQTT

สิ่งที่ผมทำ

  • ออกแบบ Schematic และ PCB Layout ด้วย EasyEDA พร้อมโมเดล 3D เพื่อประกอบบอร์ดควบคุมจริง
  • เขียนเฟิร์มแวร์ ESP32 อ่านอุณหภูมิและความชื้นในดินแบบเรียลไทม์ และสั่งรดน้ำผ่านเครือข่าย
  • เชื่อมฮาร์ดแวร์เข้ากับ Minecraft ให้ตรวจสถานะและสั่งระบบรดน้ำจากโลกจำลองได้
  • ต้นแบบแรก: command block → log ของเกม → Python → HTTP → รีเลย์ 4 ช่อง พร้อมตั้งเวลารดน้ำ 06:00 ผ่าน NTP

CH2

CPE 406 · IoT · AI · ทีม SANTA 888

Pharmacy Air Quality Monitoring

ระบบเฝ้าระวังอุณหภูมิ ความชื้น และ VOCs ในคลังยาแบบเรียลไทม์ เพื่อรักษาความคงสภาพของยา แทนการจดบันทึกหรือ Data Logger ที่ดูข้อมูลสดไม่ได้ เมื่อค่าเริ่มเข้าใกล้จุดวิกฤต ระบบแจ้งเตือนทันทีหรือสั่ง HVAC ให้ทำงานตาม setpoint

สิ่งที่ผมทำ

  • ออกแบบและพัฒนาระบบตรวจวัดอุณหภูมิและความชื้นสำหรับคลังยาตามมาตรฐาน
  • ใช้ AI ช่วยตรวจจับความผิดปกติของสภาพแวดล้อมและแจ้งเตือนความปลอดภัย
  • ออกแบบเว็บ Dashboard ให้เห็นภาพรวมและจุดเสี่ยง (Hot Spots) ทุกจุดในคลังพร้อมกัน
  • ทำงานร่วมกับทีมในการนำเสนอและแก้ปัญหาทางเทคนิค
